# Enclosure

Models made with **FreeCAD 1.1**.

- [`FreeCAD files/`](FreeCAD%20files/): source models for the Main and Server enclosures, knob cap and joystick cap
- [`STL files/`](STL%20files/): ready to print
  - `Server/`: body and lid for the guitar mounted box
  - `Main/`: body and lid for the Main pedal box. I used this to make sure my drill schematic worked, and to mockup the UV print, so I just figured I'd include it.
  - `Knob/`: knob body and marker thing. I print the body in black and marker in white using a 0.2 nozzle with my Bambu Lab A1 printer (0.4 is prob fine though). I also like printing with fuzzy skin.
  - `Joystick_Cap.stl`
- [`Tayda_Drill_Schematic.txt`](Tayda_Drill_Schematic.txt): drill template to use with Tayda Electronics, or any drilling service.

## Tayda drill template

The text file can be used with Tayda's [custom drilling tool](https://drill.taydakits.com/) for a 1590B enclosure. <br>
The columns go: **Diameter, X, Y**.
